# KYRGYZ AKYLMAN 🇰🇬

> Образовательная платформа подготовки к **Общереспубликанскому тестированию (ОРТ)** в Кыргызстане с реальными онлайн-тестами, интерактивным черновиком, аналитикой результатов, генерацией сертификатов и ИИ-помощником.

---

## ✨ Основные возможности

- 📝 **Онлайн-тестирование по разделам ОРТ:** Математика I и II (Арифметика, Алгебра, Геометрия, Анализ данных), Аналогии, Чтение и понимание текста, Практическая грамматика.
- 📐 **Интерактивный черновик (Drawing Canvas):** Возможность рисовать, чертить формулы, геометрические фигуры и графики прямо во время решения задач.
- ⏱️ **Таймер и калькулятор баллов ОРТ:** Симуляция реального регламента времени и расчет прогнозируемого балла (110–245).
- 🏆 **Личный кабинет и статистика:** Отслеживание динамики, история тестирований, целевые баллы и желаемый ВУЗ.
- 🎓 **Генерация сертификата:** Возможность скачать официальный сертификат о прохождении пробного ОРТ в PNG формате.
- 💎 **Тарифы и VIP-подписка:** Бесплатный 24-часовой VIP-триал, Доступный и Премиальный планы с материалами и видеоразборами.
- 🔐 **Авторизация:** Вход по логину/паролю и через Google (Firebase Authentication).
- 🌐 **Двуязычный интерфейс:** Полная поддержка Кыргызского (Кыргызча) и Русского языков.

## 🚀 Быстрый старт

### Требования
- [Node.js](https://nodejs.org/) (версия 18+)
- [npm](https://www.npmjs.com/) или [yarn](https://yarnpkg.com/) / [pnpm](https://pnpm.io/)

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000` (или порту, указанному в консоли).

### Сборка для продакшена (Production Build)

```bash
npm run build
```

Собранные статические файлы будут находиться в папке `dist/`.

## ⚙️ Переменные окружения (.env)

Создайте файл `.env` в корне проекта на основе `.env.example`:

```env
# Gemini API Key (для ИИ-ассистента)
GEMINI_API_KEY=""

# Firebase Authentication (Google Sign-In)
VITE_FIREBASE_API_KEY=""
VITE_FIREBASE_AUTH_DOMAIN="kyrgyz-akylman.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="kyrgyz-akylman"
VITE_FIREBASE_STORAGE_BUCKET="kyrgyz-akylman.appspot.com"
VITE_FIREBASE_MESSAGING_SENDER_ID="853874930794"
VITE_FIREBASE_APP_ID=""
```
